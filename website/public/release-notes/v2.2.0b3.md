# QwenPaw 2.2.0 Beta 3

- Merged recent upstream improvements: dual-protocol MCP Streamable HTTP with legacy fallback, stale RPC cleanup, DingTalk stale-stream detection, File Guard policy enforcement, and automatic folding of assistant process messages.
- Improved session-history reliability: history is retained by default, and `turn_usage`, rate-limit, and replay-boundary stream events now use safe heartbeat no-ops so empty SDK payloads cannot interrupt a response.
- Continued the UGSci derivation workbench improvements across flow graphs, timelines, summaries, audit data, and replay metadata; UGSci is bumped to 0.7.1.
- Fixed Console regressions in the files workspace, chat cards, mobile action menu, file previews, loop mode, and editor copy actions.
- Computer Use build artifacts and manifest are aligned at version 1.0.5.

This is a beta pre-release.
