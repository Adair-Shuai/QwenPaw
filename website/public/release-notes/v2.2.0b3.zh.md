# QwenPaw 2.2.0 Beta 3

- 合并上游近期更新：MCP Streamable HTTP 双协议与旧协议回退、僵死 RPC 清理、DingTalk stale stream 检测、File Guard 活跃策略校验，以及助手过程消息自动折叠。
- 完善会话历史可靠性：默认不清理会话，响应流中的 `turn_usage`、限流和重放边界改为安全 heartbeat，不再因 SDK 收到空响应而中断。
- UGSci 推导工作台继续增强：流程图、时间线、摘要卡、审计与重放信息保持一致，插件版本升级至 0.7.1。
- Console 修复文件工作区、聊天卡片、移动端操作菜单、文件预览、循环模式和编辑器复制等回归问题。
- Computer Use 构建产物与插件清单保持一致，版本为 1.0.5。

这是一个 beta 预发布版本。
