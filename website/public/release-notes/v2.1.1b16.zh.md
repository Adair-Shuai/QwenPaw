## 更新亮点

- 默认永久保留 Agent 会话历史和完整工具结果，只有显式设置正数保留天数时才自动清理。
- 修复有限历史保留期切换为永久保留后，仍存在于 session JSON 的旧消息无法重新导入的问题。
- UGSci 工具与可视化工作区继续保持同步，本次插件版本升级至 0.6.8。
- 对照官方 QwenPaw Computer Use 上游实现，协议方法、工具动作和安全约束保持一致，未发现缺失工具。

## 验证结果

- 会话历史、配置默认值和工具结果保留回归测试：42 项通过。
- 新版本启动验证通过，未发生历史 retention purge；启动同步恢复了仍有源文件的 355 条旧记录。
- 所有现有 Agent 配置的 `history_retention_days` 和 `offload_retention_days` 均已迁移为 `0`。
