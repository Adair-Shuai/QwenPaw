完整应用示例与验收

用明确输入 输出和判断标准验证一次完整任务。

示例一 测井质量检查

任务目标是整理 well01.las 的曲线和异常，不直接做储层定级。输入准备 LAS 文件与曲线单位说明。先选择测井分析师，确认读取与校验工具，运行只读检查；如果需要规范化导出，另存到 results。

验收：实际读入文件，列出深度范围、曲线单位、缺失值与异常段；保留检查报告；导出文件再次可读。没有岩心、地层标定等依据时，不把初步曲线检查写成正式解释结论。

示例二 储气库分层库存评价

准备每层同一采气段的采气量、注气末与评价状态压力/Z，明确压力口径、标准体积单位及周期标识。准备账面库存或同期注采账本、设计基准与需要的垫底气参数。

依次完成输入核查、综合库存计算和独立复核。验收：层系单独计算后汇总，账面库存与有效库存分开列示；保留稳定性告警、方法、输入指纹和待复核状态；不得在缺少业务审批时标注已批准。

示例三 方案排序与数模复核

为多个候选注采方案提供可比较指标，注明最大化/最小化方向、权重和约束。先用方案工具筛选可行集合，查看得分和 Pareto 标记，再选有代表性的候选送入外部数模。

验收：每个候选约束结果可见，权重与指标范围可解释，排名范围限定于本次集合；保存数模输入、许可证/版本信息和日志；数模结果与筛选建议之间的差异得到说明。

示例四 科研综述与交互报告

启用科研组件，定义检索主题和纳入标准，保存真实文献来源并区分摘要与全文。建立方法比较表，对所选计算保留参数与复算信息，再将实际数据整理为交互报告。

验收：每条引文可以追溯；图表与数据一致；HTML/PNG 导出可打开；离线 HTML 不向平台提交任务；不把模式开关启用等同于完成检索或研究。
