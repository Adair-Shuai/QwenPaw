# 井筒压力计算 · UGSci 小应用

版本 1.3.0。入口：UGSci → 应用 → 井筒压力计算。

独立移植用户提供的 `代码(1).zip` 中井筒压力计算功能，使用 UGSci 宿主 React；无需额外安装科学计算依赖、TensorFlow 或外部服务；Python 入口仅负责向 UGSci 注册应用。

## 使用

1. 左上设置井口绝对压力、温度、标况气量、总井深（测深）、Z、模型及网格精度。
2. 左下选择统一井筒或分段结构，设置流动通道内径、倾角和粗糙度。分段结构支持添加、删除和命名井段，也可导入CSV/JSON。
3. 点击“计算井筒压力”，右侧更新井身结构示意、压力/温度/流速曲线。切换“数据表”查看剖面、井段参数或工况对比。
4. Excel含参数、采样、完整剖面、模型对比、井身结构和计算检查；固定基准后附工况对比和结构对比。CSV导出当前选中的数据表。
5. 保存方案包含井身结构，兼容旧版方案；固定基准仅保留于当前页面。

修改参数后原结果标为待更新，禁止导出，防止新参数与旧结果混淆。无效参数会明确报错。

## 计算范围

保留原程序单气相采气算法，未扩展为注气或多相流计算。名称沿用原代码，Orkiszewski 和 Beggs-Brill 均为简化实现；后者仅增加 `1+0.08 sin²θ` 摩阻修正。角度相对水平面，水平0°，垂直90°。压力为绝对压力。

重力+Darcy摩阻，显式逐段积分；固定摩尔质量0.018 kg/mol，固定地温梯度0.025 K/m（按沿井筒长度），常Z；标况101325 Pa、293.15 K。没有加速项、液相持液率和储层求解。极端高速工况需单独检验假设。

统一井筒的自动网格与原界面保持一致：`max(300, round(depth))`，round采用Python的半偶舍入。井底最后一点压降梯度沿用前一网格，保持与原代码一致。

## 构建与核验

在仓库根目录运行 `node plugins/apps/wellbore-pressure/build.mjs`（使用 console 已安装的 esbuild 与 JSZip）。
`node --test plugins/apps/wellbore-pressure/tests/*.test.mjs` 核对原 Python 算法参考输出、边界、守恒、采样及无效输入。

`ui/index.js` 是可直接安装的编译入口。通过仓库 `scripts/pack/generate_plugin_metadata.py --only wellbore-pressure` 打包。

## 1.2.0 井身结构与工作台

左列上下两区，右列为贯穿的可视化工作区；窄屏自动纵向排布。

结构为沿测深连续的流动通道井段，最多30段。每段至少0.1 m，最后终点必须等于总井深；起点由上一段终点决定，避免间隙或重叠。各段内径、倾角及粗糙度参与重力与摩阻积分，网格精确落在井段边界。管径变化局部损失和加速项尚未计入。井身图按内径横向放大、按测深纵向展开，未表示真实轨迹或多层套管结构。

CSV请使用页面“CSV模板”，表头和单位为：

```csv
终点井深_m,内径_mm,夹角_deg,粗糙度_mm,井段名称
300,80,90,0.01,上部井段
700,60,90,0.01,中部井段
1000,40,90,0.01,下部井段
```

JSON支持井段数组或 `{"segments":[...]}`；字段为 `name`、`end`（m）、`diameter`（m）、`angle`（相对水平面，度）、`roughness`（m）。完整计算方案使用独立的“载入方案”入口。所有文件限100 KB；导入校验失败保留原数据与计算结果。

## 1.3.0 测斜导入与井轨迹压力耦合

左下“导入井斜”支持CSV、TSV、JSON、Excel .xlsx，文件不超过2 MB。Excel读取首个可见工作表，首个非空行为列名。MD、Inc、Azi三列须为数值；额外的狗腿度等列可忽略，三列中的Excel公式需先粘贴为数值。旧.xls请另存为.xlsx。

```csv
MD_m,Inc_deg,Azi_deg
0,0,0
200,0,0
400,20,30
600,40,45
800,60,65
1000,75,85
```

亦识别“测深(m)、井斜角(°)、方位角(°)”和MD/Inc/Azi等列名，列序可变；单位为米和度，不自动猜测英尺或弧度。JSON为测点数组或 `{"stations":[{"md":0,"inc":0,"azi":0},...]}`。

- Inc从垂直向下计，0°为直井，90°为水平井；Azi按原数据北向顺时针，0°北、90°东。未做磁偏角、海拔基准或地理坐标换算，N/E/TVD均相对井口原点。
- 支持2～2001个测点，首点MD必须为0，测深递增、间距至少0.001 m，末测深1～10000 m。近180°的相邻反向切线不能唯一确定圆弧，需补充中间测点。缺失井口或井底数据不自动外推。
- 导入后总井深同步为末测深。分段结构的最后终点同时同步；若这会与已有中间井段冲突，拒绝此次导入并保留原设置。
- 井轨迹采用最小曲率法；在测点间按圆弧插值，处理方位角跨360°，计算N/E/TVD与狗腿度。右侧支持三维旋转、垂直剖面、平面轨迹、按井段或压力着色、测深查询及SVG导出。
- 轨迹决定各处倾角，结构决定内径和粗糙度。积分网格同时包含测斜点、结构边界和基础网格；重力按垂深增量、摩阻按测深增量累计。温度默认按垂深0.025 K/m递增，可选择旧版测深基准。
- 仍沿用原程序单气相简化物性和摩阻模型，不新增多相流、加速项、变径局部损失或注气方向。未导入井斜时，保持原有单段/分段算法与默认结果。
- Excel增加“井斜测点”和“轨迹压力剖面”，有固定基准时增加“轨迹对比”。CSV可导出原始测点或轨迹压力剖面。v4方案保存井斜与温度基准，兼容v1～v3方案。
