# 地面管网

UGSci 储气库地面管网视图应用，入口 `/apps/surface-network`。二维工艺图、三维空间图、对象属性和管段表共用一个模型。内置冬季采气与夏季注气两个合成快照。切换工况更新箭头、色标和属性。色标按当前工况的范围分四档，平均端压取两端绝压的算术平均。三维管径及设备符号已放大，坐标按统一比例绘制。

左侧工程导航切换图纸和资料，模型导入与导出位于同栏底部。选中图上对象可查看右侧属性，图下可切换“测点对比”和“管段明细”。二维图右下角可缩放和恢复全图，放大后拖动平移。工具栏的“放大图面”收起侧栏与表格，按 Esc 回到工作台。

## 设备图册与站内工艺

应用内可切换井场集输总图、集注站双流程示例和设备图册。图册按井场与站场、管线与连接、阀门与保护、站内处理、增压与计量、仪表、清管与辅助分组。可按名称或代号检索，同屏查看二维符号和可旋转的三维外形。在工艺图中点选设备，再选“查看设备图例”可定位到相同部件。图例与代号是本应用的工程示意约定，施工图、厂家尺寸及项目标准以项目资料为准。

## 换成自己的数据

从页面导出模型 JSON 作为模板。每个节点使用稳定编号，`diagram` 是二维工艺图坐标，`enuM` 依次为本地东向、北向和统一基准高程，单位米。坐标原点和高程基准由项目约定。`type` 使用设备索引中的类型键，见 src/equipment.js。旧版 well、manifold、station、terminal 保持兼容。管段的 `from`、`to` 确定参考方向，`dn` 为公称直径，`viaM` 可选，按参考方向给出管线中间点的东、北、高坐标。

每个 `cases` 条目包含工况名、按节点编号给出的 `pressureMPa` 绝压和按管段编号给出的 `flow10kSm3d` 有符号流量（万标方/日），气量标况记录于 `standard`。导入后可导出当前工况的逐管段 CSV。在本机浏览器中读取和导出文件，切换项目请保留原始 JSON。本版展示输入的运行结果，UGSim 原生格式适配、水力求解与参数拟合属于后续计算模块。

## 测点与实测数据

两张示例图附带有位号和来源的合成观测。在二维或三维视图中点选位号，或在“测点对比”点击位号，右侧显示绑定对象与同一工况的模型值、实测值和偏差。默认标记指示绑定对象。已有现场坐标时，在 sensors 条目填入 enuM 指定三维点位，填入 diagram 指定二维图上位置。差压为参考起点绝压减终点绝压，流量以参考方向为正。

“测点模板”包含所有工况和测点，实测值留空。填写后导入 UTF-8 CSV，可增加新的位号。节点绝压用 MPa(a)，节点温度用 °C，管段压差用 MPa，流量用万标方/日且须与模型气量标况一致。带时区的时间戳须与模型快照精确匹配。质量可填“有效”“可疑”或“无效”，用途可填“校核”或“边界”。缺测、缺模型值、非有效和边界量均不计算拟合偏差。导入时按位号和时间更新，空值保留原记录。数据保存在本页，导出模型 JSON 可保存测点与观测，再次导入可恢复。

模型可选字段为顶层的 `sensors`（tag、target、kind、role）及每个工况的 `time`、`observations`、`temperatureC`。旧模型仍可直接查看。要对齐实测时刻，请先在相应工况中补上 `time`，例如 `2026-01-15T08:00:00+08:00`。

## eZWalker 工区

在安装版选择“eZWalker 工区”，选择一个 WLKX，可同时选择引用它的 WLP，点击导入。单选 WLP 可以核对引用文件名及视点名称。WLKX 使用本机 7-Zip 解包，支持 PATH 中的 7zz、7z、7za、7zr、Windows 默认安装的 7-Zip 或 Docker Desktop 附带的 7zr。没有解包器时可选择模型缓存的 data.db，并可附加同一工区的 model.package。安装版按用户和专家在本机保存一个工区，解析成功后切换；只读使用源文件。离线 HTML 不包含后端导入服务。

导入后从“工区总图”打开原工区。“二维总平”和“三维全貌”共享原模型的装配层级、几何和对象编号。场景按模型树与父级的平移、旋转和缩放放置构件，显示时将源模型 Y 向上转换为 Z 向上。“适合全图”恢复整个工区的范围，也可用分区列表或图上标注定位站场。全图保留可读取的圆柱和原生圆弧弯管，设备和建筑表面按分区及对象简化。工具栏的“放大图面”可展开绘图区，按 Esc 还原。点击构件可查位号、属性和关联对象；同名位号按模型树与节点号区分。

全区远景按屏幕比例绘制管线和设备，放大后按视野调入原构件。点选始终使用原装配几何。往返对象目录、图纸和工区总图可保留当前视角。安装版会为已有工区补建检索索引，浏览器可按工区版本复用已接收的装配数据。

图下“连接记录”列出源文件的端点、位号引用和焊口归属，可按对象、类型及原文检索。展开来源查看证据。“图上对照”在总图中突出两端，匹配到多个同名对象时保留原文待核。几何端面候选要求同一装配树中两端位置、方向、半径相符且互为唯一匹配，页面单列为待核对。建立 UGSim 水力模型时，工艺连接及流向仍需工艺资料确认。

“eZWalker 工区”保留详细对象目录、单件局部几何和按原始大地坐标 X/Y 绘制的井位图。已支持读取 SQLite 属性、XRE Composite v001 的 MD1 层级和已识别的几何资源。旧版索引可从保留的属性恢复关系；生成全图需要原 WLKX 或配套的 data.db 与 model.package。WLP 视点保留名称，二维总平来自三维装配的平面投影。

在仪表详情展开“绑定到测点对比”，手动选择本应用模型中的对应节点或管段。站内管线的明确 DN 字段可通过“引用源管径”采用。选择后到相应管网图页导出模型 JSON，保存来源位号、模型树和节点号。现场量程、设计压力等保留为原始属性，实测值通过测点 CSV 输入。

## 构建与验证

在仓库根目录执行 `node plugins/apps/surface-network/build.mjs`，使用 console 中的 esbuild 和 UGSci UI 已锁定的 Three.js、React 依赖构建应用及离线 HTML。宿主应用使用宿主 React。实际构建产物的页面集成测试位于 `console/src/plugins/surfaceNetwork.test.tsx`，已登记前端回归清单。
