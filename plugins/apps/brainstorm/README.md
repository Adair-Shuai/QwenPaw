# 头脑风暴

在 UGSci 应用中心打开“头脑风暴”，写下当下想弄明白的问题。比如，“如果社区读书会只开十五分钟，怎样让第一次来的人也愿意开口？” 可以直接开始，也可以先加入讨论材料。

- **继续追问**沿着刚才的回答往深处问，适合推敲假设、反例、取舍和验证办法。
- **换个视角**从另一位当事人或另一项约束重新思考。**自由发散**用类比和联想探索其他可能。两者都可以跳过当前问题。
- **生成总结**整理想法、待验证的假设和可尝试的行动，包含此时已写入回答框的内容。此后可以继续讨论并重新生成总结。
- **历史讨论**可重开已保存的问答和总结，按当前账户与专家分别保存。

支持粘贴文字、导入 TXT 或 Markdown，也支持从 DOCX、PPTX 和带文字层的 PDF 提取摘录。Word 使用段落编号，幻灯片和 PDF 使用页序。开始讨论前可编辑摘录。单份文稿上限 8 MiB，最多提取 12000 个字符，总材料上限 24000 个字符。扫描页需先识别文字。

应用路由为 `/apps/brainstorm`。讨论使用当前专家配置的对话模型。
