# 文书填报

UGSci 独立应用，地址 `/apps/document-forms`。从 Excel 读取变量配置，显示填写表单，核对后按 Word 模板生成文件。无需配置模型。

## 使用

1. 新建填报，选择 Excel 变量管理表。
2. 载入本机默认 Word 模板或添加配套模板，修改共用资料与受邀单位，保存草稿。
3. 进入核对页，处理缺项、未知变量和日期冲突。核实共用信息与输出清单后勾选确认。
4. 生成并逐份预览；可单独下载 Word，或下载包含 Word、填写数据及核对记录的整包。

填写页从上到下排列资料、受邀单位和 Word 模板，核对入口位于页面末尾。研究内容、成果、考核与进度使用较紧凑的通栏文本框，技术要求保留较大编辑空间，文本框随内容增高；核对页保留完整换行，确认按钮位于信息与输出清单之后。

添加 Word 后可将这组文件设为本机默认模板。以后新建填报会自动载入；旧草稿没有模板时可点击“使用默认模板”。默认模板按登录用户和 Agent 隔离，保存在应用数据目录，保留原文件内容，应用升级时继续使用；私人业务模板不进入公开安装包。应用提供的“入门模板”只是变量管理表、谈判文件和邀请函的通用示例，不包含原文书的业务条款。支持 `.xlsx` 与 `.docx`；旧 `.xls`、`.doc` 请先在 Office 中另存为对应格式。单个文件上限 15 MB。

## Excel 约定

“变量配置”工作表首行：`变量名称`、`中文名称`、`值`。变量名称支持 `project.name` 这样的点分层级，三列顺序可以调整。编号、电话等需要保留前导零时，应在 Excel 中保存为文本。

可增加三列：

| 列 | 含义 |
| --- | --- |
| 分组 | 表单中显示的分组名称 |
| 类型 | `text`、`textarea`、`date`、`datetime-local`、`number`；省略时按字段和内容推断 |
| 必填 | 默认“是”，填“否”可允许留空 |

“受邀单位”工作表首行：`单位名称`、`领取开始时间`、`领取结束时间`。可增加或移除单位。时间支持 Excel 日期单元格、ISO 日期时间和常见中文日期，导入后转换为日期控件。

后续单位的空白领取时间默认跟随第 1 家，新增单位也会跟随。手动修改开始或结束时间后，仅该项改为独立填写，另一项继续跟随；可点击“恢复跟随”。保存、重新打开与导出再导入 Excel 均保留这一状态。Excel 可增加“开始时间跟随首家”“结束时间跟随首家”两列，填写“是”或“否”；未提供时已有明确时间按独立填写保留。

兼容未写入行列范围的 Excel，以及带括号说明的表头，例如“受邀单位（invitation.recipient）”“邀请函领取开始（YYYY-MM-DD HH:MM）”。编号为空白单位预留的行会保留供补充，表后的说明行不会成为单位。

“校核规则”工作表可选，首行：`校核项`、`开始变量`、`结束变量`、`允许相同`。起止列引用变量名称；允许相同默认“是”，填“否”时要求严格先后。应用自动检查常见发文、答疑、响应截止及谈判日期，核对各单位领取时间。`dates.issue` 为共用落款；如同时配置 `dates.invitation_issue`，要求两者一致。业务日期检查是完整性与先后关系检查，不代替采购规则审核。

“日期校核”中的既有结果及公式缓存不用于放行生成。每次核对均依据当前表单值计算。导出 Excel 包含当前填写值、单位、规则及本次检查快照；继续修改 Excel 后应重新导入核对。

发放、答疑及谈判时段支持完整起止时间，例如 `2026-07-25 14:30 ~ 2026-07-25 17:30`。表单保留原文，校核会比较时段内部顺序、前项结束与后项开始，以及各单位领取时间是否落在总体发放期内。响应截止必须早于谈判开始。

输入变量、受邀单位和规则中的公式会提示改为明确值，避免将缓存值当作新数据。原 Excel 的其他工作表及样式不随导出复制；原文件不会被修改。

## Word 约定

共用变量：`{{ project.name }}`、`{{ dates.issue }}` 等。支持段落、表格、页眉页脚及被 Word 拆为多个文字样式段的占位符，使用 docxtpl 保留模板原有版式。

邀请函可使用 `{{ invitation.recipient }}`，或 `{{ invitation.start }}` / `{{ invitation.end }}`。包含这些变量的模板按受邀单位分别生成，其余模板生成一份。邀请函中的 `{{ events.invitation_time }}` 使用该单位的领取时段；共用文件中的同名变量使用 Excel 配置的总体发放时段。若 Excel 未配置该变量，仅使用它的旧式模板仍按单位生成。项目及落款继续共用。

文书与核对页统一采用中文日期。纯日期如“2026年9月30日”，时间点如“2026年10月22日下午14:30”，同日时段如“2026年10月22日下午14:30至17:30”；跨上午、下午时注明两端时段，跨日时保留两端完整日期。进度安排中的“2026.11-2026.12”显示为“2026年11月至2026年12月”。时钟采用 24 小时制，不改动实际日期时间；项目编号、电话、金额和资质起始年份保持原值。Word 正文、表格、页眉和页脚使用同一转换逻辑。

日期选择器保留标准值；文本时段和进度框按文书写法显示，编辑后可识别中文时间。导出 Excel 增加“文书显示”和“领取时段（文书）”列，原始输入值保留以供校核和重新导入。新版批次采用中文日期，历史批次保留并标明“原日期格式”。

模板变量需与 Excel 配置相符；未配置变量、漏填及日期冲突均阻止生成。使用受限 Jinja 环境，不支持函数调用或下标取值。支持按单位名单重复表格行及评分页；图片占位符、函数调用和复杂宏不属于当前输入约定。

## 保存与兼容

草稿保存于宿主工作目录的 `apps/document-forms`，按登录用户和 Agent 隔离。点击保存、导出、核对或添加模板会保存当前修改。每次生成保留独立批次，修改后旧批次标明过期；生成失败不会留下半批成功文件。并发页面修改通过修订号检测冲突。

前端优先通过宿主 `workspace.loadPreview()` 嵌入现有 `ArtifactPreview` / Office 渲染链路。已发布宿主尚未提供该接口时，通过同一 `/workspace/convert-office` 服务在应用内预览，可单独安装应用使用。预览保真程度沿用宿主 OfficeCLI / 兼容渲染能力。


页面集成回归加载实际 `ui/index.js`，验证宿主内嵌 Office 组件以及已发布宿主的共用转换服务；后端回归读取真实 XLSX/DOCX，检验三家单位分别生成、统一落款、格式与转义、日期冲突、作用域隔离、确认失效及原子生成。

独立发布流程为 `document-forms-release.yml`。测试与可重复构建检查通过后，使用仓库已有插件打包器生成此应用的安装包，校验远端内容后登记市场目录，保留其他应用与历史版本。版本化安装包发布后不覆盖。


## 文书名称与现场表格

模板名称统一为“序号_文书名称_模板.docx”，生成文件为“序号_文书名称_项目名称.docx”；按单位生成的文件追加“单位序号_单位名称”。标准文书包含商务谈判文件、谈判邀请函、投标报价一览表、综合评分表、综合评分汇总表。导入时识别旧文件名中的工作备注并使用正式名称；序号按模板清单顺序排列。历史批次保留原有文件名和内容。

邀请函和报价表按单位分别生成。共用表格可用 `participants` 循环输出全部单位，用 `participant.name` 引用名称；使用 docxtpl 的 `{%tr for participant in participants %}` 行标记重复源表格行。评分页可使用 `participant_groups` 按三家一组循环，`group.first`、`group.second`、`group.third` 为该组单位名称，不足三家留空。这样增加单位时不挤窄原表格的手写评分栏。以上变量由当前受邀单位名单提供，Excel 不应配置同名变量。

综合评分表显示“建议打印 7 份，每位专家一份”，只生成一份可打印文档。报价金额、分数、排序和签字栏由现场填写；应用不会推算或预填这些结果。现有本机业务模板继续沿用其评分标准、分值、纸张及合并单元格。

整包下载名包含项目、生成时间和批次标识，内部填写数据及核对记录也带项目名称。重复或长单位名称仍以独立序号区分，文件名过滤 Windows 不允许的字符。私人模板只保存在当前用户与 Agent 的本机默认库中。

文件预览页顶部的“一键打包下载”下载最新批次的全部 Word 文书、填写数据 Excel 和核对记录；各历史批次的“下载此批次”只下载该次生成的文件，保留原文件内容与压缩包名称。下载失败会提示重试，下载操作不会重新生成文件。

默认预览采用 OfficeCLI 调用本机 Word 的实际打印页面，所有页按一列连续显示，保留评分表边框、合并单元格和签字栏分页，可调整预览比例。“文字预览”继续使用宿主现有 Office 组件。实际打印预览需本机可用的 OfficeCLI 与 Word，最多 40 页；不具备时明确提示切换文字预览或下载 Word。页面图按文书内容缓存于私有应用目录，不改变生成文书，也不加入下载包。

打印预览逐页生成和显示，每页独立适应宽度，横竖版混排不会将竖页补成横页的宽度；先展示已完成的页面，后续页面继续载入，保留页码及缩放。隔离的只读副本避开旧 OfficeCLI 常驻进程丢失页码参数的问题，预览完成后清理副本。原文件及已生成批次保持不变。

表单中的多段文字按换行生成独立 Word 段落，每段复制模板占位处的首行缩进、字体和行距；段内自动折行仍由 Word 排版。私人默认模板的字体修正只应用于该模板库，应用不会统一覆盖用户自行上传模板中的字体。
