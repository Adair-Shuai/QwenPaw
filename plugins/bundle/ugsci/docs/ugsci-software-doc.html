什么是 UGSci？

UGSci（UnderGround Science）是面向石油天然气领域的 QwenPaw 增强插件。它将 QwenPaw 的通用 AI Agent 界面重新组织为石油领域友好的 "专家 — 能力 — 技能" 三层架构，让油气行业的工程师、地质学家和研究人员能够用自然语言与 AI 助手交互，完成从数据处理到数值模拟的全流程工作。

💡 一句话理解：UGSci 就像给一位通用的 AI 助手"穿上"了石油工程师的工作服——它不仅懂得行业术语，还能直接操作 Eclipse、CMG、COMSOL 等专业软件。

UGSci 能做什么？

🛢️
油藏数值模拟
用自然语言启动 Eclipse / CMG / COMSOL 模拟，自动监控收敛性，读取并分析结果——无需手写脚本。
📡
测井与地震解释
读取 LAS 测井文件、SEG-Y 地震数据，自动计算孔隙度、饱和度、泥质含量等地层参数。
👥
多专家协同
将多个 AI Agent 编为专家团队——测井分析师、地球物理专家、油藏工程师——以流水线、协调者或圆桌讨论模式协作。
🔧
本地软件检测
自动扫描主机已安装的油气仿真软件（CMG、Eclipse、Petrel、tNavigator 等 12 款），检测结果注入 Agent 上下文。
📊
数据分析与可视化
内置 40+ 技能，涵盖统计建模、机器学习、优化算法、大数据处理，自动生成图表和报告。
🎯
历史拟合辅助
系统性调整模型参数，自动评估敏感度，迭代优化拟合度——让繁重的拟合工作半自动化。

UGSci 与 QwenPaw 的关系

QwenPaw 是一个开源的个人 AI 助手框架（由 AgentScope 团队开发），支持多渠道聊天、多 Agent 协同、技能系统和定时任务等功能。UGSci 是 QwenPaw 的领域增强插件——它不修改 QwenPaw 的核心代码，而是通过插件机制注入石油领域的专业知识、工具和界面。

快速开始

前提条件

  • QwenPaw v2.0.0+ 已安装并运行（安装指南）
  • 浏览器：Chrome / Edge / Firefox（用于访问 Console 控制台）
  • 大语言模型：已配置至少一个模型（如 Qwen、GPT 等）
  • （可选）模拟软件：Eclipse / CMG / COMSOL 已安装（用于数值模拟功能）

安装步骤

  1. 复制插件到 QwenPaw 插件目录

    将 UGSci 插件目录复制到 QwenPaw 工作目录的 plugins/ 子目录下：

    # Linux / macOS
cp -r plugins/bundle/ugsci ~/.qwenpaw/plugins/

# Windows (PowerShell)
Copy-Item -Recurse plugins\bundle\ugsci $env:USERPROFILE\.qwenpaw\plugins\
  2. 重启 QwenPaw 后端

    重启后，UGSci 插件将自动加载。启动时会自动完成：

    • 同步 40+ 内置技能到共享技能池
    • 初始化默认计算引擎配置（Eclipse / CMG / COMSOL / Intersect / tNavigator）
    • 注册模拟控制工具（6 个 Agent 工具）
    • 注册 HTTP API 路由（引擎管理、头像生成、模拟监控）
  3. 打开 Console 控制台

    在浏览器中访问 http://127.0.0.1:8088/，左侧导航栏将出现 UGSci 的四个模块入口。

  4. 配置计算引擎

    进入 能力中心 → 计算引擎，点击「自动检测」按钮扫描已安装的模拟软件，或手动填写可执行文件路径。

  5. 创建第一个专家

    进入 专家中心，点击「创建专家」，选择模板（如"油藏工程师"），系统会自动填充系统提示词和审批级别。

  6. 开始对话

    在聊天界面中，对专家说："帮我分析一下 case1.DATA 的模拟结果"——Agent 将自动调用模拟工具完成分析。

💡 提示：如果您不需要数值模拟功能，只需完成步骤 1-3 即可开始使用 UGSci 的专家对话和技能功能。

技能中心

技能中心展示了 UGSci 内置的 40+ 个专业技能。这些技能在插件启动时自动同步到 QwenPaw 的共享技能池，用户可以按需下载到任意 Agent。

技能是什么？

在 QwenPaw 中，技能（Skill）是一组指导 Agent 如何完成特定任务的 Markdown 文档。它包含：

  • 工作流程：步骤化的操作指南
  • 代码模板：可复用的 Python 代码片段
  • 领域知识：专业术语、公式、判断规则
  • 工具依赖：该技能需要的 Agent 工具列表

💡 类比：如果说 Agent 是一位工程师，那么技能就是他读过的"操作手册"——工程师可以有很多手册，遇到具体问题时翻阅对应的那一本。

SSE 实时监控 API

UGSci 提供了基于 Server-Sent Events (SSE) 的实时模拟监控接口，前端可以订阅模拟任务的进度更新：

# 订阅模拟任务状态（SSE 流）
GET /api/ugsci/sim/jobs/{job_id}/stream

# 列出所有模拟任务
GET /api/ugsci/sim/jobs

SSE 事件每 5 秒推送一次，包含状态、PID、已运行时间、剩余时间等信息。当任务达到终态（completed / failed / timeout / error）时，流自动关闭。

模拟工作流

UGSci 内置了 reservoir-simulation-workflow 和 history-matching 两个模拟工作流技能，指导 Agent 按标准流程完成油藏数值模拟。

历史拟合工作流

history-matching 技能指导 Agent 进行系统化的历史拟合，包括四个阶段：

  1. 基准运行

    启动初始模型，读取结果，计算与历史数据的误差（产油量相对误差、压力绝对误差、含水率误差）。

  2. 参数敏感性分析

    系统修改单个参数（渗透率 ±20%/±50%、孔隙度 ±10%、相渗端点等），评估对结果的影响。每次只改一个参数以确定因果关系。

  3. 迭代修正

    优先调整敏感度最高的参数，每轮迭代后重新评估拟合度。内置判断规则表，如"产油量偏高→降低渗透率"、"见水过早→调整相渗曲线"等。

  4. 验证

    最终运行确认所有指标达标，生成性能报告并导出完整结果。

💡 拟合目标：产油量相对误差 < 5%，地层压力绝对误差 < 0.5 MPa，含水率转折点时间误差 < 3 个月。

计算引擎管理详解

UGSci 的计算引擎管理系统负责管理模拟器的配置信息——包括可执行文件路径、许可证服务器、模块列表等——并自动将这些信息注入到 Agent 的系统提示词中。

引擎能力摘要注入

当 Agent 启动时，UGSci 会自动生成一份简洁的引擎能力摘要，注入到 Agent 的系统提示词中。这让 Agent 知道：

  • 哪些引擎已就绪（已检测到安装）可以直接调用
  • 哪些引擎已配置但尚未检测到安装
  • 每个引擎的调用方式和参数约定
  • 必须使用 launch_simulation 等工具，而非直接 shell 调用模拟器

自动检测

点击「自动检测」按钮，UGSci 会扫描以下位置：

  • Windows 注册表中的已安装程序
  • 常见安装路径（C:\Program Files\、C:\Program Files (x86)\）
  • 用户自定义扫描路径
  • PATH 环境变量中的可执行文件

⚠️ 许可证检测：对于 Schlumberger 软件（Eclipse / Intersect），UGSci 会尝试使用 lmutil.exe 检测许可证状态。如果许可证不可用，引擎状态会标记为 "no_license"。

专家团协作

专家团是 UGSci 的多智能体协同功能，允许将多个石油领域专家 Agent 组编为团队，以不同模式完成复杂任务。

三种编排模式

🔗 流水线模式 (Pipeline)

专家依次执行，上一步结果作为上下文传递给下一步。适用于有明确先后顺序的工作流。

示例：储层评价团队

  • 测井分析师 → 岩性识别与孔隙度计算
  • 地球物理专家 → 储层预测与含油气检测
  • 油藏工程师 → 储量评估与开发建议

🎯 协调者模式 (Coordinator)

由协调者 Agent 主导，按需咨询其他专家，综合所有结果输出方案。适用于需要综合判断的复杂任务。

示例：钻井设计团队

  • 钻井工程师（协调者）→ 井身结构与套管设计
  • 地球物理专家 → 地层压力预测
  • 采油工程师 → 完井方案建议

💬 圆桌讨论模式 (Roundtable)

各专家独立评估同一任务，不传递其他专家的意见，最后对比综合。适用于需要多视角对比的评审。

示例：开发方案评审团队

  • 油藏工程师 → 储量与开发方式评估
  • 钻井工程师 → 工程可行性评估
  • 采油工程师 → 生产工艺评估

常见问题

UGSci 需要安装专业模拟软件才能使用吗？

不需要。UGSci 的专家对话、技能系统和多 Agent 协同功能不依赖任何模拟软件。数值模拟工具链（launch_simulation 等）需要已安装 Eclipse / CMG / COMSOL 等模拟器才能使用，但其他功能（测井分析、数据可视化、统计分析等）不受影响。

UGSci 支持哪些模拟器？

目前支持 Eclipse (E100/E300)、CMG (IMEX/GEM/STARS)、COMSOL Multiphysics、Intersect 和 tNavigator。每种模拟器都有对应的适配器，处理命令行参数、日志解析和结果读取。

模拟运行期间会消耗 Token 吗？

不会。使用 wait_for_simulation 工具时，Agent 在内部轮询模拟状态，不发送任何 API 请求，因此零 Token 消耗。模拟完成后才恢复对话。

专家团的任务模板中的 {占位符} 是什么？

占位符是任务模板中的变量。例如 {区块名} 和 {井号}，在发起任务时系统会弹窗让你输入具体值，然后替换到任务描述中发送给协调者 Agent。

自定义专家团会丢失吗？

自定义团队存储在浏览器的 localStorage 中。如果清除浏览器数据或更换设备，自定义团队会丢失。建议导出保存。预设团队不受影响。

UGSci 支持中文吗？

支持。UGSci 的界面、技能文档和系统提示词均支持中英文。Agent 可以用中文或英文与用户交流，取决于模型配置和用户偏好。

如何添加自定义技能？

在技能池目录中创建新的技能文件夹，包含 SKILL.md 文件即可。UGSci 启动时会自动同步到技能池。也可以通过技能市场在线安装。

模拟任务在服务重启后会丢失吗？

不会。模拟任务元数据持久化到 JSON 文件中。服务重启后，UGSci 会自动恢复任务状态——如果模拟进程仍在运行，状态保持 "running"；如果进程已结束，状态更新为 "completed"；如果已超时，状态标记为 "timeout"。

UGSci 与 QwenPaw 的关系是什么？

UGSci 是 QwenPaw 的领域增强插件。它不修改 QwenPaw 的核心代码，而是通过插件机制注入石油领域的专业知识、工具和界面。升级 QwenPaw 不影响 UGSci（只要版本兼容），卸载 UGSci 也不影响 QwenPaw 的正常使用。
