快速开始

  1. 安装插件：

    cp -r plugins/bundle/ugsci ~/.qwenpaw/plugins/

  2. 重启 QwenPaw 后端

  3. 切换到极简模式：

    localStorage.setItem("qwenpaw_sidebar_mode", "simple");

  4. 刷新页面，开始使用专家中心、能力中心、技能中心和市场

模块路由说明
