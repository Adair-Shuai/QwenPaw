使用指南

本指南面向最终用户，介绍 UGSci 插件的安装、配置和日常使用。

快速开始

1. 安装插件

将 ugsci 目录复制到 QwenPaw 工作目录的 plugins/ 子目录下：

cp -r plugins/bundle/ugsci ~/.qwenpaw/plugins/

重启 QwenPaw 后端后，插件自动加载。打开浏览器控制台，搜索 [ugsci] 可确认注册成功。

2. 切换到极简模式

UGSci 的四大模块菜单仅在 Simple Mode 下显示。在浏览器地址栏执行：

localStorage.setItem("qwenpaw_sidebar_mode", "simple");

刷新页面后，左侧导航栏会出现四个新菜单项：

菜单 图标 路由
专家中心 🧑‍🔬 /ugsci-experts
能力中心 🔌 /ugsci-capabilities
技能中心 ⚡ /ugsci-skills
市场 🏪 /ugsci-market

如需恢复完整模式：localStorage.setItem("qwenpaw_sidebar_mode", "full")

专家中心

浏览专家

打开 专家中心 页面，可看到所有已创建的 Agent 以专家卡片形式展示。每张卡片显示：

  • 专家名称和功能简介
  • 已安装技能数量
  • 关联的 MCP 客户端数量
  • 启用/停用状态

在搜索框中输入关键词，可按名称、描述或技能名过滤专家。

查看专家详情

点击任意专家卡片，右侧弹出抽屉面板，展示完整配置：

  • 基本信息：名称、描述、工作目录、模型信息
  • 技能列表：该专家已安装的全部技能
  • MCP 客户端：关联的 MCP 客户端及其工具
  • 系统提示词：配置的系统提示词文件路径
  • 审批级别：AUTO（自动执行）或 MANUAL（需人工审批）

召唤专家

点击专家卡片上的 「召唤专家」 按钮，系统会：

  1. 将该专家设为当前选中 Agent
  2. 自动跳转到聊天页面
  3. 即可直接开始对话

如果专家未启用，召唤按钮会提示先启用。

创建专家

点击 「创建专家」 按钮，弹出模板选择窗口。从 6 个内置模板中选择：

模板 说明 审批级别
🛢️ 油藏工程师 储量评估、物质平衡、数值模拟 自动
⛏️ 钻井工程师 井身结构、钻井液、套管设计 需审批
📡 测井分析师 曲线解释、岩性识别、参数计算 自动
⚙️ 采油工程师 举升工艺、注水管理、增产措施 自动
🌍 地球物理专家 地震解释、反演、储层预测 自动
🧪 PVT 分析师 流体物性、相态分析、PVT 拟合 自动

点击模板卡片后，系统自动创建 Agent，预填系统提示词和审批级别。创建完成后回到专家列表即可看到新专家。

专家团

切换到 「专家团」 标签页，可使用多智能体协同功能。

使用预设团队

内置 4 个预设专家团：

  1. 储层评价团队 🛢️ — 流水线模式，测井→地球物理→油藏工程
  2. 钻井设计团队 ⛏️ — 协调者模式，钻井工程师主导
  3. 开发方案评审团队 📋 — 圆桌讨论，三位专家独立评估
  4. 流体性质分析团队 🧪 — 流水线模式，PVT→地球物理→油藏

点击团队卡片的 「发起任务」 按钮：

  • 如果任务模板包含 {占位符}（如 {区块名}），会弹出输入框
  • 输入具体任务描述后点击「发起任务」
  • 系统自动将编排指令发送给协调者 Agent
  • 页面跳转到聊天页，协调者开始按步骤咨询各专家

前提：团队中所有成员对应的 Agent 必须已创建。卡片上会显示 3/3（全部找到）或 2/3（缺少成员）的状态标签。

创建自定义团队

点击 「创建专家团」 按钮，在弹出的构建器中填写：

  1. 基本信息：团队名称、emoji 图标、类别、描述
  2. 编排模式：选择流水线、协调者或圆桌讨论
  3. 选择成员：从已有 Agent 列表中选择团队成员
  4. 任务模板：编写任务模板，可使用 {参数名} 占位符
  5. 编排指令：编写协调者 Agent 的系统级指令

保存后，自定义团队会显示在列表顶部（带「自定义」标签），支持编辑和删除。

注意：自定义团队保存在浏览器 localStorage 中，清除浏览器数据会丢失。不同浏览器/设备间不共享。

能力中心

MCP 客户端

打开 能力中心 页面的 「MCP 客户端」 标签，可查看所有已配置的 MCP 客户端。每张卡片显示：

  • 客户端名称和 Key
  • 传输方式（stdio / SSE / Streamable HTTP）
  • URL 或启动命令
  • 提供的工具数量
  • 启用/停用状态

点击卡片可查看详细信息。点击 「管理 MCP」 跳转到 QwenPaw 原生 MCP 管理页面。

本地软件检测

切换到 「本地软件检测」 标签，可查看主机上已安装的油气仿真软件。

查看检测结果

软件卡片按类别分组显示（油藏数值模拟、地质建模、测井分析等）：

  • ✅ 绿色标签「已检测」：找到已安装的软件，显示版本和路径
  • — 灰色标签「未安装」：未在系统中找到

重新检测

点击 「重新检测」 按钮，系统重新扫描所有标准路径和自定义路径。

添加扫描路径

如果软件安装在非标准路径下，点击 「添加扫描路径」：

  1. 输入自定义目录路径（如 D:\MySoftware\CMG）
  2. 系统会添加该路径并重新扫描
  3. 自定义路径会保存，后续检测都会包含

能力摘要

检测结果会生成一份 Markdown 格式的能力摘要，可注入 Agent 系统提示词，让 Agent 知道本地安装了哪些软件及其调用方式。

技能中心

打开 技能中心 页面，可浏览共享技能池中的所有技能。

浏览技能

技能卡片展示：emoji、名称、描述、版本号、标签。使用搜索框可按名称、描述或标签过滤。

查看技能详情

点击任意技能卡片，右侧弹出抽屉面板，展示：

  • 技能完整描述
  • 来源（customized / system 等）
  • 版本信息
  • 已安装此技能的专家列表

安装技能到专家

  1. 在技能详情中查看哪些专家已安装了该技能
  2. 如需安装到更多专家，点击 「管理技能池」 跳转到技能池管理页面
  3. 在技能池页面选择目标 Agent 并下载安装

UGSci 插件内置的 44 个技能在启动时自动同步到技能池，不会自动安装到任何 Agent，需用户按需下载。

市场

打开 市场 页面，可搜索和安装远程技能，或使用专家模板创建新专家。

技能市场

在 「技能市场」 标签中：

  1. 在搜索框输入关键词（如 matplotlib、reservoir）
  2. 可选择分类进行筛选
  3. 搜索结果以卡片形式展示：名称、描述、来源、版本、作者
  4. 点击卡片查看详情
  5. 在详情面板中选择目标 Agent，点击 安装
  6. 安装进度通过进度条实时显示

专家模板

在 「专家模板」 标签中，可浏览和一键创建专家：

  1. 浏览 6 个内置石油领域专家模板
  2. 点击模板卡片直接创建 Agent
  3. 系统自动填充系统提示词、审批级别等配置
  4. 创建完成后可在专家中心看到新专家

常见问题

插件菜单不显示

原因：未切换到 Simple Mode。

解决：在浏览器控制台执行：

localStorage.setItem("qwenpaw_sidebar_mode", "simple");

然后刷新页面。

专家团成员显示「缺少成员」

原因：团队中某些成员名称与实际 Agent 名称不匹配。

解决：
1. 查看团队卡片上的成员列表
2. 在专家中心创建缺少的专家（使用对应的专家模板）
3. 确保专家名称与团队成员名称一致

技能池中没有 UGSci 的技能

原因：后端启动时技能同步钩子未执行或失败。

解决：
1. 检查后端日志中是否有 [ugsci] Synced N skill(s) to skill pool
2. 确认 skills/ 目录存在且包含 SKILL.md 文件
3. 重启 QwenPaw 后端

本地软件检测找不到已安装的软件

原因：软件安装在非标准路径下。

解决：
1. 在能力中心的「本地软件检测」标签中点击「添加扫描路径」
2. 输入软件的安装目录
3. 点击「重新检测」

自定义专家团丢失

原因：自定义团队保存在浏览器 localStorage，清除浏览器数据后丢失。

预防：定期手动备份。在控制台执行：

JSON.parse(localStorage.getItem("ugsci_custom_teams"));

将结果保存到文件，后续可通过 localStorage.setItem() 恢复。

最佳实践

专家命名

  • 使用与专家模板一致的名称（如「油藏工程师」「测井分析师」），确保专家团能正确匹配
  • 避免在名称中使用特殊字符
  • 同一领域只创建一个对应专家

技能管理

  • 按需安装技能，不要给单个专家安装过多技能
  • 油气领域技能建议成组安装（如 oil-gas-foundation + oil-gas-drilling）
  • 定期在技能中心检查技能版本和更新

团队使用

  • 流水线模式适用于有明确先后顺序的工作流
  • 协调者模式适用于需要综合判断的复杂任务
  • 圆桌讨论适用于需要多视角对比的评审场景
  • 任务模板中的占位符应使用有意义的名称（如 {区块名} 而非 {a}）
