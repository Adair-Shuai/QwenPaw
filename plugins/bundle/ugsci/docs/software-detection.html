本地软件检测

UGSci 的“引擎”页面用于登记和检查本机已经安装的专业计算软件。它不会凭空安装软件，也不会因为检测到软件就自动启动正式计算。

你能做什么

  1. 查看已经登记的引擎：GET /api/ugsci/engines/list。
  2. 查看能力摘要：GET /api/ugsci/engines/summary。
  3. 自动检测本机软件：POST /api/ugsci/engines/detect。
  4. 忽略缓存重新检测：POST /api/ugsci/engines/detect/refresh。
  5. 手动新增、修改或删除引擎：分别使用 POST /api/ugsci/engines/、PUT /api/ugsci/engines/{engine_id} 和 DELETE /api/ugsci/engines/{engine_id}。

页面操作

进入“工具·技能 → 引擎 → 仿真软件”，先点击“自动检测”。对结果逐项检查软件名称、版本、可执行文件路径、安装目录、许可证和模块路径。状态为“待配置”或“路径无效”时，点击配置按钮修正，不要直接开始仿真。

安全建议

  • 首次运行只做检测，不提交计算任务。
  • 将仿真输入复制到独立的 working 目录，原始 deck 和结果目录只读备份。
  • 许可证、服务器地址和账号信息不要写进截图、报告或公共技能说明。
  • 在 Windows 上优先选择实际的 .exe 文件；不要手工拼接路径分隔符。

常见问题

自动检测不到软件

请确认软件确实安装在当前电脑、当前用户有访问权限，且可执行文件没有被安全软件隔离。点击“配置”手动选择可执行文件后，再使用“检测”验证。

路径无效

这通常表示软件升级或移动过目录。重新选择路径并保存；如果团队共享配置，请让每台电脑分别验证，不要复制另一台电脑的绝对路径。
