## 本次修正与限制

- 合并冲突逐处处理，没有全文件覆盖增强实现。
- 契约测试发现顺序改为稳定排序，解决并行测试收集不一致。
- 前端测试范围限定源码，避免扫描旧桌面打包产物。
- 上游新测试中的示例插件补齐当前版本兼容范围，未放宽实际插件版本保护。
- 工作区隔离测试允许两边都有内置 NeqSim，仍断言自定义驱动不得串入另一工作区。
- Windows 虚拟环境启动器与实际 Python 进程的 PID 不同；命名退出事件测试改用实际解释器复验通过，未改变运行时代码。
- Creator 使用经上游固定 SHA-256 验证的 jq 1.8.2、UTF-8 模式、禁用冲突的 pytest base_url 插件，并用独立测试插件缩短临时目录名复验；未修改产品代码来绕过断言。Windows 扩展路径写法会干扰解压与媒体工具，因此最终使用普通短路径。
- Windows 长路径用例使用较短临时目录复验。25 项符号链接用例无法在当前权限下建立测试夹具，仍未验证；未修改系统权限或掩盖失败。
- 未进行真实付费模型调用、外部 IM 通道联调、macOS/Linux 桌面安装验证，也未发布或推送到远程。

测试证据保存在工作区 `.codex-tmp/upstream-20261015/`，包括原始日志和 JUnit XML。上述复验统计基于对应失败用例重新执行，不代表再次完整重跑所有已通过的用例。
