# FlowForge 业务验收记录

验收分支：`lobehub-style`。日期：2026-10-25。本报告依据该分支重新执行的测试，不采用其他分支或此前环境的测试数字。

## 验收范围与方法

目标是验证自然语言创建/修改工作流、可视化编排、确定性业务计算、并行汇合、审批、持久恢复、版本追溯和取消在同一系统中的行为。

新增独立业务验收位于 `tests/unit/plugins/flowforge/test_business_acceptance.py`。测试使用真实 `WorkflowService`、`RunLifecycleMixin`、执行器、调度器、SQLite 工作流版本与提案仓库、JSON 运行记录/检查点。重启场景关闭旧服务后台循环，再由新服务读取原持久目录。

工具入口使用真实 `AgentNodeCatalog`、`QwenPawLocalWorkspace.list_tools`、`GovernedWorkflowTools`、`PolicyGuardedTool` 和 `ResourceGovernor`。隔离测试策略设为 `smart`，仅显式注册测试计算工具为 internal；没有将审批级别设为 OFF，也没有替换权限检查或直接注入裸工具调用。测试记录真实策略决策，撤销注册后断言函数从未执行。

外部库存函数是确定性假实现，模型响应是受控 fixture。它们用于验证执行协议和变更行为，**不构成真实业务数据准确性、真实模型理解质量或外部服务可用性的验收**。

## 独立业务验收结果

以下 **17 项全部通过**，最近独立执行耗时 5.45 秒。参数化场景分别计数。

| 场景 | 验收断言 |
| --- | --- |
| 并行汇合与低偏差正常分支 | 账面库存为 `100 + 12 - 8 = 104`；两种计算必须同时到达同步点才继续，串行调度会失败；比较节点在两者完成后执行一次。压力库存 103 时偏差 `1/104`，仅输出正常报告 |
| 偏差高于 3%，审批通过 | 压力库存 95，偏差 `9/104`，先等待人工审核且无终端报告；通过后仅输出批准报告 |
| 偏差高于 3%，审批拒绝 | 拒绝后仅输出拒绝报告，不进入批准路径 |
| 非法审批决定 | 字符串 `"false"` 被拒绝，不创建续行或占用原暂停记录；之后合法布尔拒绝仍可完成 |
| 单流程重启恢复 | 暂停后改写定义，再重启；按原快照和原修订完成，不重复三项业务计算 |
| 动态目录后的权限撤销 | 目录已准备且工具仍在工作区，但真实策略注册被撤销；调用被拒绝，函数无副作用 |
| 拒绝不可重试：类型化工具 | `Tool.publish_report` 配置 2 次重试仍只进行一次拒绝决策 |
| 拒绝不可重试：通用工具 | `ToolNode` 同样不重试策略拒绝 |
| 拒绝不可重试：兼容工具 | `ToolCallNode` 同样不重试策略拒绝 |
| 未知工具失败 | 未注册工具被拒绝或运行明确失败，无成功下游报告 |
| 真实运行取消 | 取消正在等待的治理工具，实际协程退出，持久状态为 cancelled，下游不发布 |
| 父子流程重启与版本追溯 | 子流程审批暂停后删除父、子定义并重启；已有快照仍可恢复，父子 revision、root/parent/resumed-from 关联正确，业务计算不重复 |
| 父取消传播到子 | 父流程取消后，正在执行的子工具实际退出；父子记录均取消且不可恢复 |
| 两个并行子流程分别审批 | 通过 `node_id` 与 `child_inputs` 分层指定目标；先批准一个仍保持另一个暂停，再拒绝另一个；两份结果结构保持正确，各计算仅执行两次 |
| 自然语言创建 | 提案前传入真实专家可用目录；预览不保存、不运行工具；应用后得到 revision 1，实际运行库存流程成功 |
| 自然语言阈值修改 | 3% 改 5% 只改变条件，其他节点/布局保留；预览不修改保存内容，应用后 4% 偏差走正常路径 |
| 自然语言提案版本冲突 | 生成提案后有较新人工修订，过期提案不能覆盖人工变更，原阈值保持 3% |

## 本轮集成中发现并修复的问题

独立验收发现并回归了以下跨模块问题：新能力校验误拒绝已删除定义的存量子运行恢复；父子审批的 `node_id` 被错误传给下一层；多次恢复后，JSON 检查点把子流程结果的输出槽位恢复为列表导致输出形状变化；运行记录缺少固定 `flow_revision`。这些问题均由实现负责模块修复，验收断言保持对应业务要求。

另外修复了模型适配器没有消费宿主流式响应的问题，并补充真实协议的最终响应去重、流关闭、异常、取消、超时及自然语言提案集成回归。

另通过真实治理执行链检查了 `retryable=False`：权限拒绝在配置重试预算时仍只决策一次，不重复调用。

## 当前适用范围与尚需的生产验收

当前实现适用于单主机、单服务执行所有者。SQLite 提供版本写入、提案应用和恢复占用的事务互斥；活动任务、取消信号、JSON 运行记录和检查点仍需单所有者协调，不能据此宣称已经支持多 worker 或跨主机高可用。

DAG 并行、汇合、审批、已接入的真实 `SubworkflowNode`、有界迭代和真实评分质量门已具备对应实现与回归入口。嵌套 `ParallelNode` 分支执行没有接入宿主执行器，目录标记不可用；应通过独立画布节点表示并行。

脚本使用可超时、可取消的独立 Python 子进程；这是执行隔离，不是防御恶意代码的安全沙箱。对不可信代码仍需 OS/容器隔离。已提交到真实外部系统的副作用无法通过取消回滚，业务工具必须另行验证幂等键、重试策略和事务边界。

正式业务上线前仍需使用目标专家、真实模型、生产工具/凭据和代表性数据验证：自然语言编排正确率、真实数据单位与精度、权限隔离、模型/网络异常、外部调用幂等性、负载与资源限制、备份恢复、进程崩溃时副作用和检查点之间的边界，以及采用多 worker 时的协调方案。这些未测项目不计入本次通过数字。
