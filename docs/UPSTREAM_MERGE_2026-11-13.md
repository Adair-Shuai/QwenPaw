### 30. [`19363e606`](https://github.com/agentscope-ai/QwenPaw/commit/19363e606)：保留工具 Schema 的布尔禁止项（#8607）

工具 Schema 清理器保留 `additionalProperties: false` 等四类关键字原生的 `false` 拼写，不再变成部分兼容服务忽略的 `{"not": {}}`。此前可能导致模型看到一个没有参数的函数，表现为工具调用缺少字段。

这不是取消 Schema 校验：其他布尔 Schema 和 `true` 的既有处理保持，嵌套 Schema 同样覆盖。对我们使用结构化工具和 FlowForge JSON Schema 的场景尤其需要检查，但不改写业务 Schema 或放宽本地结构化输出验证。

### 31. [`04fcf09f5`](https://github.com/agentscope-ai/QwenPaw/commit/04fcf09f5)：Office COM 自动化进入审批（#8048）

识别 PowerShell、Python 等内联创建或附着 Word／Excel／PowerPoint／Outlook COM 对象的命令，避免沙箱关闭时直接进入无审批回退。Office COM 可能附着用户已经打开的应用，调用 `Quit()` 会关闭用户窗口。

同时修正规则优先级：CRITICAL 检测不能被宽泛 ALLOW 规则吞掉，应进入正常审批，而不是仅凭严重程度直接禁止。保留我们的 OfficeCLI 引擎、预览、宏内容和文书生成流程；不通过关闭审批或改成任意 COM 调用来兼容现有功能。

### 32. [`f47dd19bd`](https://github.com/agentscope-ai/QwenPaw/commit/f47dd19bd)：卷根目录不写沙箱 ACE（#8018）

Windows 沙箱不能在盘符根、UNC 共享根等卷根目录写入可继承的授权项，否则可能影响整个卷的权限范围。后端对提升和非提升两条沙箱路径都增加根目录防护；前端在选择此类项目目录前提示，并覆盖会话项目、默认工作区等入口，不能仅检查显式路径。

用户确认采用卷根目录时，相关执行使用上游规定的无沙箱路径，而不是悄悄修改整盘 ACL；不能以普通项目目录路径测试替代该边界。合并保留我们的多项目根、文件预览身份和实际路径校验。
