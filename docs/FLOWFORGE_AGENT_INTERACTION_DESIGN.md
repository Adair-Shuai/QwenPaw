# FlowForge 工作流助手交互设计

设计稿 v1，2026 年 11 月 13 日。对应《FlowForge 持续对话编辑器前后端设计》v2 的专用专家、流程会话与调试经验方案。

工作台采用画布与右侧工作流助手并排的布局。专用助手在当前流程中持续对话，用户通过消息中的变更卡片完成修改与验证。调试产生的问题、失败尝试和有效修复进入经验页，后续任务可以引用适用的经验。

## 页面结构

### 工作台顶部

顶部保留当前工作流名称、保存状态及修订。进入其他工作流时，画布、对话、未发送文字和流程经验一起切换至对应作用域。

助手入口使用“工作流助手”。助手打开后，工作台为画布重新分配可用空间。当前业务执行专家显示在画布工具区，专用工作流助手身份显示在聊天栏顶部。

选择节点后，可从节点卡片的“AI 修复”或运行观察的“用此记录分析”进入同一个流程会话。来源运行和修订随消息记录，节点定位、属性编辑与运行观察在画布区域完成。

### 右侧助手

助手栏默认宽度为 400px，包含以下区域。

| 区域     | 内容与操作                                                               |
| -------- | ------------------------------------------------------------------------ |
| 身份区域 | 工作流助手名称、当前会话标题、所属工作流，以及会话历史、新对话和收起操作 |
| 内容切换 | “对话”和“经验”，经验数量对应当前流程的问题与经验记录                     |
| 消息区域 | 普通答复、澄清、修改卡片、验证计划、实际结果和经验引用                   |
| 输入区域 | 当前选区、运行或经验引用、消息输入、自动或仅讨论，以及发送或停止         |

点击工作流助手名称展开身份信息，查看专用模型配置、工作流知识和操作能力，并能从正式界面进入现有专家设置。执行专家以单独的上下文展示，切换后重新核对节点能力。

“经验”页在助手栏内展开。返回“对话”后恢复原会话及未发送文字。查看经验详情时，可以定位来源运行或引用通用经验。

## 进入工作流与恢复会话

打开工作流时，恢复该账户在该流程最近使用的会话。消息、当前修订、已应用卡片和活动任务可继续查看。打开助手、收起助手和返回页面均沿同一个会话接续。

新流程展示简短空状态及“解释这个流程”入口。有失败运行时可以直接点击节点上的 AI 修复。

“新对话”创建该流程下的新会话，当前流程经验继续可用。会话历史仅展示当前流程的会话，用户可以切回之前的讨论。每段会话分别保存未发送文字和显式引用。

切换到另一工作流后恢复另一段对话。后台生成按发起时的流程和会话完成，结果回到原会话。返回原流程时可查看该轮结果。

## 从失败到修复经验

### 读取与诊断

点击“AI 修复”自动附带当前节点、运行 ID、失败修订和选区。助手读取该运行的错误、配置和实际输入输出，在对话中说明判断依据。

首次观察到问题时自动保存问题记录。消息中展示紧凑的“问题已记录 · 待验证”入口，点击可查看原始错误、原因判断和后续尝试。

用户单独询问原因时先得到解释，继续要求修改时在同一对话生成方案。信息不足时，助手在消息内提出问题及可点选答案。

### 修改卡片

修改卡片显示变更主题、涉及节点及当前状态，默认展开简短说明和操作。“查看具体修改”展开字段、脚本或连接差异。

“预览变更”将画布切换到变更视图。预览栏提供“返回编辑”，退出后保留真实草稿和原视口。助手对话继续可见。

“应用并保存”先按最新草稿及保存修订检查方案。成功后原卡片变为“已应用 · r7”等实际状态，输入框继续接受下一条消息。

卡片提供“回退修改”。先展示回退范围，用户确认后保存新修订。相关字段有后续手工修改时，显示当前值与回退值，由用户解决重叠修改。

### 同输入验证

已应用卡片提供“用本次输入验证”。计划明确显示执行目标、当前修订和输入来源，用户可以选原失败输入或边界样本。

验证使用当前脚本与配置。原运行提供可复用的业务数据，界面可查看实际采用的输入。存在未保存修改时，计划标明将保存的草稿修订。

执行期间消息显示真实运行阶段及停止入口。结果卡片记录实际运行 ID、修订、样本和结果，并可打开完整运行观察。

失败后显示“继续修复”和“查看失败尝试”。下一轮引用新失败记录，原来的要求、尝试和方案保留在会话中。

### 经验更新

验证完成后，经验页更新本次尝试及结果。失败记录继续显示待验证，成功修复显示已验证。可复用规则根据实际验证提炼适用条件，进入同账户通用经验。

用户看到“修复经验已保存”的简短反馈。点击进入经验页查看总结、验证记录及适用条件，后续继续在原对话中工作。

## 经验页

### 本流程

列表展示当前流程的问题、原因判断及修复记录。每条记录显示标题、简短总结、状态和来源数量。详情包含问题总结、尝试与验证、原始错误和管理操作。

状态文案使用“待验证”“已验证”和“已失效”。同一问题可以同时保留失败尝试和后来的成功结果，来源显示各自修订及输入样本。

用户可编辑经验总结，真实错误和验证记录作为来源单独展示。标记失效后保留历史来源。删除经验前在当前详情内确认具体记录。

### 通用经验

列表展示已验证的工作流规则及其适用节点和版本。原始业务数据通过各自流程的来源记录访问。

“在对话中引用”将该条经验作为可见引用附在输入区，用户可继续补充要求。发送后，助手结合当前流程的节点和数据复核适用性，并在答复中保留经验来源入口。

已失效经验保留状态并停止参与正常引用。切换到另一流程后，可以检索适用的同账户通用规则，当前流程的私有问题和聊天从各自记录读取。

### 示例验证路径

原型以字段错误展示一次可操作的学习过程。

1. 实际输入含 `sales=0`，旧脚本读取 `sale`，产生字段错误。
2. 应用字段修复，使用零值样本验证，记录修复结果与字段契约经验。
3. 选择 `sales=null` 的边界样本，检查数值运算的空值处理。
4. 如验证失败，保留失败尝试，继续生成显式空值处理方案。
5. 验证成功后，在经验页查看多次尝试，并在另一工作流引用适用规则。

## 手工编辑与冲突

用户可在生成期间调整节点名称、参数和位置。助手以发起时的上下文生成方案，应用前对最新草稿检查。

独立修改自动合并。例如手工重命名节点后，字段修复仍保留该名称。重叠修改在卡片内显示原值、当前值与 AI 建议。

用户选择“保留当前”或“采用 AI”后重新检查整张卡片。冲突解决前，应用操作展示明确的待处理状态。对话保持连续，用户也可以发消息解释新的要求。

## 对话中的状态反馈

| 状态           | 界面反馈                                           |
| -------------- | -------------------------------------------------- |
| 已接纳消息     | 用户消息进入当前流程会话，保留请求身份             |
| 正在读取或生成 | 显示实际工作阶段，输入框可继续编辑，主按钮提供停止 |
| 需要澄清       | 同一条消息显示问题及选项，支持自由输入             |
| 修改就绪       | 展示可预览的修改卡片                               |
| 草稿有冲突     | 卡片内定位节点及字段，并提供对应选项               |
| 应用成功       | 原卡片记录实际修订，输入继续可用                   |
| 验证失败       | 显示实际错误和继续修复入口，保存尝试               |
| 验证成功       | 显示实际执行范围、结果和经验保存入口               |
| 连接中断       | 保留消息和草稿，恢复后按服务端状态接续             |
| 专家暂不可用   | 提供明确原因及既有配置入口，保留当前输入           |

状态文字紧邻对应消息或卡片。错误、来源和待处理操作使用必要提示。常规操作使用简短状态反馈，详情按需展开。

## 窄屏与可访问性

- 可用工作区至少 900px 时并排显示，助手宽度可在 320px 至 560px 间调整，画布保留至少 480px。
- 600px 至 899px 时，助手作为可收起的侧面覆盖层打开。
- 小于 600px 时，使用“画布”和“助手”切换整宽视图，恢复时保留上下文与视口。
- 输入法组合输入期间保留 Enter 输入行为。常规 Enter 发送，Shift 加 Enter 换行。
- 所有图标操作具有可读名称。状态同时通过文字表达，关键操作支持键盘。
- 调整栏宽、打开详情和切换工作流时，焦点与阅读位置有明确归属。
- 主题与中英文沿用宿主，用户业务名称、脚本和变量保持原文。

## 设计稿检查范围

交互原型使用示例流程、预置答复和本地演示状态，供体验界面、操作顺序及状态反馈。正式会话持久化、专家调用、经验库和运行结果由后端方案实施。

重点检查以下路径。

- 字段修复应用后继续对话，消息和经验来源可见。
- 切换两个工作流，各自恢复对应会话与输入。
- 新对话与历史切换时，流程经验仍可查阅。
- 零值样本与空值样本分别验证，失败尝试可追溯。
- 验证后生成通用经验，在另一流程引用并复核。
- 手工改字段产生冲突，手工重命名随修复保留。
- 经验总结可编辑，失效状态和删除操作明确。
- 窄屏下对话、经验、属性和画布操作可达。
