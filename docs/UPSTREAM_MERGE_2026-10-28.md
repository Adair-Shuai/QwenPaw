## 桌面兼容处理

上游桌面将 Console 固定打进本机窗口，本分支另有独立前端组件更新能力。因此保留小型 bootstrap 跳转到后端提供的已校验前端，以及相应原生命令和回环权限；共享后台的生命周期与窗口分离。后台实例变化后重启当前窗口以重新加载前端组件。

共享守护进程在每次重启时重新解析活动组件，保留 Python 运行时/依赖层、OfficeCLI、Node、Java/NeqSim 环境和失败回退。它清除最初组件带入的环境路径，避免回退后仍加载旧层；以真实 `/api/version` HTTP 成功响应确认启动，不把仅存在发现记录视为成功。

共享后台发现记录绑定组件协议和原生宿主指纹，版本与活动后端组件匹配，防止把已兼容安装的较新组件错判为非法后台，也防止跨不兼容宿主接管。Windows 便携更新继续使用原有可见更新助手，在其就绪后交接安装进程身份，保留多窗口更新锁；NSIS 和 macOS 更新继续保留原有签名与只读位置检查。
