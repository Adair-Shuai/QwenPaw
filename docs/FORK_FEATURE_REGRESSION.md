# 自有功能合并回归

FlowForge 执行器将输入模式校验、初始状态、调度恢复、完成路由及审批载荷分别处理，保留执行次序、原有截止时间与取消行为。检查点通过图对象的公开接口保存可见节点和显式分支决策，空分支、临时节点及重开时的路由清理继续保留。`test_executor_stage_contract.py` 经两份实际插件的公开执行、旁路与磁盘重启恢复入口，保护默认值与显式零、元数据优先级、审批校验、已完成并行节点不重复执行，以及图快照与内部容器的隔离；原有并行、迭代、错误处理、展开及超时回归继续执行。测试不调用外部模型、求解器或下载服务。

FlowForge 路由分组注册时须保留全部接口的顺序、模式与 HTTP 错误响应。实时 WebSocket 订阅使用实际进度注册表的公开 handler 接口及每连接线程安全队列，重订阅、断线和结束均释放该连接自己的 handler；历史快照与队列交接处的同一事件只发送一次，取消后先排空进度再发送终态，重启后的持久化回放与 SSE 行为继续保留。`test_router_stream_contract.py` 经两份插件的实际 FastAPI／Starlette ASGI 路由、WorkflowService、内置 WaitNode／OutputNode 和 ProgressRegistry 验证上述行为，不能仅用模拟进度队列替代。

UGSci 原生储气库处理器由独立实例持有注册时解析的适配器与请求类型，Run Center 继续负责调度和生命周期；保留七种计算的参数包优先级、零值、取消检查，以及来源信息先于结果事件的持久化顺序。依赖缺失仍在原有注册边界隔离，模拟和可视化桥仍独立绑定且不受加载顺序影响。`test_native_storage_executors.py` 经两份插件的公开注册入口及真实 RunExecutorService、ExecutionContext 和 SQLite 仓库验证上述行为；原有兼容宿主和插件注册回归继续执行。

TaskTracker 在广播取消、异常或提前结束时，须先关闭源异步流再进入宿主完成回调，避免源流停在 yield 时继续持有插件调用。`test_tracker_stream_cleanup.py` 通过实际队列锁和取消，在宿主持久化仍暂停时验证源流已关闭、插件可安全重载；同时保留没有 aclose 方法的普通异步迭代器、原有事件和终态交付行为。

Pylint 经完整模块名区分插件命名空间，避免不同应用的 backend、engine 等同名模块共用错误解析结果。包装器只替换确实指向原文件的模块参数，初始化文件保留完整的 __init__ 模块后缀，避免变成包名后递归检查未选中的子文件；无法映射的脚本原样交给检查器，不执行包初始化器，不缩减 pre-commit 选中文件、原有检查选项或错误退出位；`test_pylint_namespace.py` 保护这些边界。GitHub 的全量 pre-commit 检查继续执行。

FlowForge 编辑器节点归并、配置补全及类型推断分别处理，保留 config、class_type、data.type、原始 type 和图标的既有优先级；显式空参数、零超时、工具别名、外层 metadata 以及自动补齐的起止节点不能丢失。`test_authoring_conversion_contract.py` 在两份实际转换器上经 canonical loader 验证完整节点、输入、控制字段和原始数据不变，原有画布执行及工作流定义回归继续执行。

## 已确认的丢失原因

`@ Agent` 功能来自 `eabd10f96`，曾在 `b9e3b2a1d` 中适配上游。上游合并 `7cf038d00` 后，AgentMention 组件及其单元测试仍在，但聊天页面不再挂载选择器，也不再处理提交中的指派意图。仅运行组件测试无法发现这种断开接线的问题。

恢复时沿用现有 SDK 的不可变提交上下文，在异步状态检查、输入清空之前保存指派目标及协作方式，前台和后台队列使用同一个请求转换入口。界面保留用户原文，请求保留附件、消息身份及审批设置。

## 保护范围

新建 UGSci 团队工作流启用成果版本协议：主控按计划步骤为每轮分派准备独立候选路径，只有当前 attempt 的非空 JSON 候选可以发布；正式结果保留不可变快照及 SHA-256，兼容路径由主控发布工具生成。审核报告必须匹配 review_id 和整组成果版本，FAIL/PARTIAL 不能进入综合阶段；重做任一步使旧审核失效，即使结果字节相同也需要新审核。最终报告绑定通过审核的版本，状态推进、完成 gate 和收尾均复核完整性。中断后未提交的快照不能被视为审核通过，原样重试可恢复；旧实例保留原有查询行为，不追溯伪造版本证据。

固定回归 `tests/unit/plugins/ugsci/test_team_artifacts.py` 包含迟到覆盖、重复派发、并发冲突、非法候选、篡改与崩溃恢复，并冻结计划依赖、绑定候选使用的输入版本，阻止上游重做后继续使用旧下游成果；其中 `test_system_host_sdk_workflow_rework_restart_and_history` 经真实宿主模式注册、slash 命令、SDK FunctionTool、状态 gate、中间件和 HTTP 查询，验证六种团队模式的分派、退回重做、重新审核、重启恢复和完成历史。系统集成使用合成数据，不调用外部模型或私人账户；不能替代真实模型长任务和所有桌面平台的验证。文件工具拦截属于接口保护，任意 Shell 脚本的完全隔离仍需操作系统沙箱，不改动 AgentScope 基础协作实现。

团队状态及成果工具还须由模式 setup 注册到宿主治理目录，归属 `ugsci`，由插件卸载和重载撤销；模式工具不能只加入运行工具列表而遗漏权限注册。系统回归通过真实 PolicyGuardedTool 和 ResourceGovernor 检查权限后再执行，不以裸 FunctionTool 调用代替。进入审核及后续阶段前校验真实 fork 集成与布尔确认；`current_phase=completed` 但尚为 active 的实例可由原主控恢复，且仅能补交集成确认，不能重开阶段、改成果或修改终态实例。

UGSci 专家团状态持久绑定 `owner_session_id`，重启恢复必须匹配控制会话；子任务、其他同 Agent 会话及无归属旧实例均不能自动接管。主控通过模式专属状态工具按 `revision` 增量更新，严格拒绝非法字段、生命周期身份改写、过期快照及终态重开；宿主文件工具直接改写团队 state.json 会被 UGSci 扩展中间件拦截，其他业务文件继续可用。Shell 是通用执行能力，此拦截属于工具接口保护，不替代操作系统沙箱；续行提示明确禁止脚本改写团队状态。旧实例仍可查询历史，不静默迁移控制权。
