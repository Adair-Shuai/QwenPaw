# 自有功能合并回归

FlowForge 编辑器节点归并、配置补全及类型推断分别处理，保留 config、class_type、data.type、原始 type 和图标的既有优先级；显式空参数、零超时、工具别名、外层 metadata 以及自动补齐的起止节点不能丢失。`test_authoring_conversion_contract.py` 在两份实际转换器上经 canonical loader 验证完整节点、输入、控制字段和原始数据不变，原有画布执行及工作流定义回归继续执行。

插件中断等待器收尾仍会让出事件循环，重载须在该收尾结束后读取实际调用及终态回调占用，不能使用收尾前的任务快照误报忙碌。`test_mutation_observes_release_during_waiter_teardown` 在截止边界释放最后一次插件调用，同时保留宿主任务，验证无需延长超时便可继续重载；原有拒绝清理、每轮仅重试一次及终态交付门禁保持不变。

FlowForge 节点执行流水线按输入解析、惰性输入、带重试的执行和输出收尾拆分；缓存命中仍早于惰性输入和执行，瞬态错误保持指数退避及原有次数上限，取消不转成重试或写入缓存。`test_runner_pipeline_contract.py` 在两份真实节点执行器上保护嵌套连线、默认值深拷贝、实例复用、指纹与三种缓存绕过、进度上下文、旧输出规范化、阻塞节点和子图展开门禁；原有工作流超时、结构化错误及治理拒绝回归继续执行。

FlowForge 工具适配器的参数模式推导拆为独立类型转换步骤，保留必填项、默认零值、原生模式对象、容器和 Optional 参数及复杂类型的旧兜底行为；节点包继续公开既有节点类、注册表 getter、reset 和 bootstrap，旧注册表缺少 getter 时仍复用兼容实例。`test_public_adapter_contract.py` 同时覆盖两份插件，验证公共适配器和节点入口，避免以重复类型声明或更换导出掩盖行为变更。

插件重载的清理门禁只跟踪仍持有插件调用或终态回调的任务；同一个宿主任务完成插件调用后，继续保存聊天完成时间不能使旧插件永久繁忙。`test_mutation_releases_invocation_before_host_task_finishes` 验证调用退出后宿主任务仍存活时可重载；真实 app/channel 的 provider 清理拒绝与公开重载回归将宿主完成回调暂停在事件上，验证失败清理仍阻止替换、释放后可重试。FlowForge 错误日志回归在父级处理器格式化前复制日志记录，保留异常对象类型检查，同时验证实际输出的完整回溯和原始错误。

## 保护范围

新建 UGSci 团队工作流启用成果版本协议：主控按计划步骤为每轮分派准备独立候选路径，只有当前 attempt 的非空 JSON 候选可以发布；正式结果保留不可变快照及 SHA-256，兼容路径由主控发布工具生成。审核报告必须匹配 review_id 和整组成果版本，FAIL/PARTIAL 不能进入综合阶段；重做任一步使旧审核失效，即使结果字节相同也需要新审核。最终报告绑定通过审核的版本，状态推进、完成 gate 和收尾均复核完整性。中断后未提交的快照不能被视为审核通过，原样重试可恢复；旧实例保留原有查询行为，不追溯伪造版本证据。

固定回归 `tests/unit/plugins/ugsci/test_team_artifacts.py` 包含迟到覆盖、重复派发、并发冲突、非法候选、篡改与崩溃恢复，并冻结计划依赖、绑定候选使用的输入版本，阻止上游重做后继续使用旧下游成果；其中 `test_system_host_sdk_workflow_rework_restart_and_history` 经真实宿主模式注册、slash 命令、SDK FunctionTool、状态 gate、中间件和 HTTP 查询，验证六种团队模式的分派、退回重做、重新审核、重启恢复和完成历史。系统集成使用合成数据，不调用外部模型或私人账户；不能替代真实模型长任务和所有桌面平台的验证。文件工具拦截属于接口保护，任意 Shell 脚本的完全隔离仍需操作系统沙箱，不改动 AgentScope 基础协作实现。

团队状态及成果工具还须由模式 setup 注册到宿主治理目录，归属 `ugsci`，由插件卸载和重载撤销；模式工具不能只加入运行工具列表而遗漏权限注册。系统回归通过真实 PolicyGuardedTool 和 ResourceGovernor 检查权限后再执行，不以裸 FunctionTool 调用代替。进入审核及后续阶段前校验真实 fork 集成与布尔确认；`current_phase=completed` 但尚为 active 的实例可由原主控恢复，且仅能补交集成确认，不能重开阶段、改成果或修改终态实例。

UGSci 专家团状态持久绑定 `owner_session_id`，重启恢复必须匹配控制会话；子任务、其他同 Agent 会话及无归属旧实例均不能自动接管。主控通过模式专属状态工具按 `revision` 增量更新，严格拒绝非法字段、生命周期身份改写、过期快照及终态重开；宿主文件工具直接改写团队 state.json 会被 UGSci 扩展中间件拦截，其他业务文件继续可用。Shell 是通用执行能力，此拦截属于工具接口保护，不替代操作系统沙箱；续行提示明确禁止脚本改写团队状态。旧实例仍可查询历史，不静默迁移控制权。

已准入的 TaskTracker 进入终结阶段后标记为清理任务，使后续非中断重载能等候其收尾；仍不重新开放普通业务请求。`test_sdk_channel_routing_contract.py` 也加入固定后端清单，保护阻塞终结通知后的公开重载重试与流终结的三个生命周期入口。
