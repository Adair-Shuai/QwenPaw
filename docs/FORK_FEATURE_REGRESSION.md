桌面应用名称必须保留插件 `registerRoutes` 的静态／本地化标签，即使 `/apps/` 路由不进入侧栏菜单；新版菜单接口的函数标签也必须保留。桌面图标、Dock、启动台搜索、菜单栏、窗口标题及窗口总览统一解析当前语言，语言切换不能重挂载应用或丢失草稿。仅未声明名称时才回退为路由名。`console/src/os/DesktopAppLabels.test.tsx` 通过真实宿主注册器、文书填报发布产物和实际桌面页面验证，已纳入固定前端清单；不替代已安装桌面包验收。

`@ Agent` 功能来自 `eabd10f96`，曾在 `b9e3b2a1d` 中适配上游。上游合并 `7cf038d00` 后，AgentMention 组件及其单元测试仍在，但聊天页面不再挂载选择器，也不再处理提交中的指派意图。仅运行组件测试无法发现这种断开接线的问题。

恢复时沿用现有 SDK 的不可变提交上下文，在异步状态检查、输入清空之前保存指派目标及协作方式，前台和后台队列使用同一个请求转换入口。界面保留用户原文，请求保留附件、消息身份及审批设置。

## 保护范围

新建 UGSci 团队工作流启用成果版本协议：主控按计划步骤为每轮分派准备独立候选路径，只有当前 attempt 的非空 JSON 候选可以发布；正式结果保留不可变快照及 SHA-256，兼容路径由主控发布工具生成。审核报告必须匹配 review_id 和整组成果版本，FAIL/PARTIAL 不能进入综合阶段；重做任一步使旧审核失效，即使结果字节相同也需要新审核。最终报告绑定通过审核的版本，状态推进、完成 gate 和收尾均复核完整性。中断后未提交的快照不能被视为审核通过，原样重试可恢复；旧实例保留原有查询行为，不追溯伪造版本证据。

固定回归 `tests/unit/plugins/ugsci/test_team_artifacts.py` 包含迟到覆盖、重复派发、并发冲突、非法候选、篡改与崩溃恢复，并冻结计划依赖、绑定候选使用的输入版本，阻止上游重做后继续使用旧下游成果；其中 `test_system_host_sdk_workflow_rework_restart_and_history` 经真实宿主模式注册、slash 命令、SDK FunctionTool、状态 gate、中间件和 HTTP 查询，验证六种团队模式的分派、退回重做、重新审核、重启恢复和完成历史。系统集成使用合成数据，不调用外部模型或私人账户；不能替代真实模型长任务和所有桌面平台的验证。文件工具拦截属于接口保护，任意 Shell 脚本的完全隔离仍需操作系统沙箱，不改动 AgentScope 基础协作实现。
