# 自有功能合并回归

## 已确认的丢失原因

`@ Agent` 功能来自 `eabd10f96`，曾在 `b9e3b2a1d` 中适配上游。上游合并 `7cf038d00` 后，AgentMention 组件及其单元测试仍在，但聊天页面不再挂载选择器，也不再处理提交中的指派意图。仅运行组件测试无法发现这种断开接线的问题。

恢复时沿用现有 SDK 的不可变提交上下文，在异步状态检查、输入清空之前保存指派目标及协作方式，前台和后台队列使用同一个请求转换入口。界面保留用户原文，请求保留附件、消息身份及审批设置。

## 固定回归入口

在 `console` 目录运行：

```text
npm run test:fork-features
npx tsc -b --noEmit
```

`scripts/verify-fork-features.mjs` 维护必需测试清单。文件缺失、关键页面集成用例被移除都会失败。前端 CI 在全量 Vitest 覆盖率测试之前先检查该清单，因此测试不能因上游合并被悄悄删掉而继续通过。

## 保护范围

| 功能 | 必须保留的行为 |
| --- | --- |
| @ 选择 | 中英文输入框保留 @ 指派 Agent 提示；在真实 ChatPage 输入 @ 出现候选列表，过滤当前及禁用 Agent，键盘确认只插入提及 |
| 直接指派 | 单一目标写入请求和路由，发送文本去除该提及，附件保留 |
| 协作 | 单 Agent 的协作选择、多个 Agent 的顺序分工，均由当前 Agent 协调 |
| 队列与 SDK | 输入清空、后续输入、排队、重试、编辑及页面切换不改变已提交消息的目标 |
| 扩展应用 | 安装／更新后刷新卡片和详情，等待重启与已安装状态区分 |
| 软件更新 | 检查结果与版本说明对应，失效缓存清理，真实核心及组件更新继续可见；更新指引仅说明桌面端操作，不展示源码／命令行安装或跳转上游发布页 |
| 工作区与插件 | 四方框入口能打开、从预览展开及关闭当前会话工作区；选择文件后可返回预览；聊天输入、编辑器及子弹层的 Esc 不误关面板；切换会话不串文件，关闭后重开保留当前运行中的未保存编辑；较晚完成的旧文件请求不能覆盖新选择；计算工作区直接打开且不抢占后续文件请求；UGSci 侧栏与工作流接口继续连接 |
| UGSci 设置 | 在设置中心统一管理 UGSci 功能，GenUI 为其中一项；旧 GenUI 地址跳转到设置中心，主侧栏不再保留独立 GenUI 入口；开关读写与后端不可用保护继续有效 |
| 文书填报应用 | 实际打包页面读取 Excel 后挂载表单，编辑后保存并核对，用户勾选确认后才能生成；生成文件调用宿主现有 Office 预览，后续修改显示旧文件提示。后端回归使用真实 Excel/Word，覆盖独立邀请函、共用落款、占位符、日期冲突、作用域隔离和批次原子生成；兼容缺失／错误行列范围、带说明表头与不等长行，时间段按起止点校核，总体发放与独立邀请函时段正确分离，不能借错误范围绕过大小及公式检查 |

清单覆盖上述具体功能，不代表全部产品行为都有端到端验证。以后新增自有功能应同步登记行为、回归用例及需要的本地界面验证。发布桌面版之前仍需验证实际安装包。

Office 预览优先使用 OfficeCLI 的完整 HTML 与脚本，保留原文书字体、页边距、分页、横向纸张及表格。OfficeCLI 探测失败后应在短时缓存到期后重试，不能永久判定不可用；简化预览结果不阻止重新打开时升级到 OfficeCLI。`OfficeDocRenderer.test.tsx` 已加入必需清单，验证简化结果后的重新转换及完整 HTML 的脚本沙箱；后端 `test_workspace_office.py` 验证运行期间 OfficeCLI 恢复可用。

文书填报的日期、起止时段、封面与落款统一使用中文日期，进度中的年月写法同步整理。表单展示与核对页沿用同一服务端文书值，原始日期控件值和 Excel 输入值保留；更改其他字段不能顺带重写日期。实际页面回归核对中文时段展示及保存数据；后端回归覆盖中文日期往返解析、跨上午下午和跨日、正文表格页眉页脚的格式保留、Excel 文书显示列，以及业务编号与年份不被误改。

文书填报的填写页按表单、受邀单位、Word 模板、核对入口顺序排列，核对与生成区域保持在末尾。长段落使用通栏文本框，研究内容、成果、考核与进度从较紧凑高度按内容增高，技术要求保留较大空间；进入核对页后长段落也通栏显示。后续单位领取时间逐项跟随第 1 家，手动修改只解除对应项，保存和 Excel 往返后继续保留，且可恢复跟随。本机默认 Word 模板按用户与 Agent 隔离，新建填报自动载入，旧草稿可主动载入；模板原件不进入公开包。实际打包页面回归验证底部入口的位置、换行编辑、时间跟随与独立修改、默认模板保存、确认生成及两种 Office 预览路径；后端验证跟随状态持久化、默认模板完整性与隔离。布局宽度和窄窗口适配另做浏览器检查。

工作区回归同时覆盖真实 ChatPage 的顶部按钮与事件接线，以及 FilesDrawer、FilesWorkspace、状态转换和会话隔离。窄窗口（宽度不超过 1024 像素）使用覆盖聊天区域的面板；应在浏览器检查关闭按钮始终可见，关闭后恢复聊天。文件树范围沿用现有实现。未保存编辑只保证当前运行中的面板关闭／重开，不代表刷新或退出程序后仍可恢复。

UGSci 相关设置统一扩展 `ui/src/settings/UgsciSettingsPage.ts`，入口为 `/settings/ugsci`。插件只注册页面组件，设置中心承载统一入口；旧 `/ugsci-genui-settings` 保留兼容跳转。`ugsciSettings.test.tsx` 对两份实际打包插件验证导航、GenUI 保存与重新进入、后端不可用保护及旧地址跳转。

更新能力和后续发布产物的保护规则见 `docs/UPDATE_COMPATIBILITY_GUARD.md`，固定后端入口为 `python scripts/verify_update_regressions.py`。

队列清单包含真实 ChatPage 的 SDK 宿主契约和实际后台发送函数的交接测试；更新 @ 指派接线时，同时验证纯附件排队、挂起请求交还前台、释放发送锁和真实 HTTP 失败处理。测试夹具使用实际指派上下文解析器，输入框解析支持同一事件被多个页面控制器读取。

文书填报保留报价表按单位生成、综合评分按三家分组、汇总表按当前名单增减行，评分打印份数与正式文件名在实际打包页面显示。后端使用合成真实 Word 表格覆盖 1、3、4 家单位、空白报价及评分栏、受限名单变量、文件名长度与字符、历史批次内容不变；私人业务原件不进入公开测试和安装包。

打印版式预览通过宿主已有 OfficeCLI 生成全部实际 Word 页面，保留文字预览组件作为切换选项。回归覆盖连续全页渲染参数、按文书内容缓存、用户与 Agent 隔离、不可用提示、图像资源释放、缩放，以及从打印版式切回两种宿主文字预览路径；页面图不进入文书下载包。

文书填报的多行文本生成真实段落，复制模板的首行缩进、行距与字体；后端真实 Word 回归覆盖正文、表格和页眉的各段格式及特殊字符。打印预览按单页获取和缓存，实际打包页面逐页挂载并保留缩放、资源释放与文字预览切换；横竖版混排需另以 OfficeCLI 实测页面尺寸，竖页不补齐横页画布宽度。

文件预览页各批次标题右侧保留“打包下载”按钮，当前及历史批次使用同一位置的入口，顶部不单独占用下载区域。实际打包页面回归验证入口位置、当前与历史批次的请求、压缩包名称、失败重试，以及下载不重新生成文书；后端真实 ZIP 回归验证 Word、Excel 和核对记录完整，预览图不进入压缩包。

文书填报随应用提供五份已清理作者及旧 Office 插件信息的标准 Word 模板与空白配套 Excel。本机自设默认模板优先，字段匹配的导入表在全新目录自动载入自带模板；其他 Excel 仍可搭配自己的 Word。实际页面回归覆盖自动载入及配套下载；后端真实 Excel/Word 回归覆盖无本机模板时生成九份文件、跨 Agent 使用、空白字段、个人模板优先和损坏资源拒绝。发布器在上传前校验完整模板清单、摘要、空白配置及文档隐私结构，不允许本机数据目录、项目原件或额外文件进入应用包。

文书填报以项目归集六阶段材料；首次迁移只新增项目索引，不改写旧草稿、模板和输出。项目底稿只填充新表单的空白字段，已有表单须逐项选择同步，校验项目和表单修订并失效原确认。前序材料及表单变化提醒后续阶段复核；阶段办结须人工确认与必备材料检查。材料附件保留版本并按用户和 Agent 隔离，阶段默认模板不能覆盖谈判库。项目／阶段打包包含目录 Excel、底稿、模板、附件版本及历史批次，缺失或损坏文件不得静默漏包。实际打包页面覆盖项目六阶段、附件版本、办理信息、手工确认、资料差异与未保存保护；后端使用真实文件覆盖迁移、继承、阶段默认库、双修订同步、旧文件不变、范围隔离及完整 ZIP。
