## 一、新增及明显增强的功能

### 1. 顾问模式：两个模型协作完成任务

智能体可使用一个模型作为顾问，另一个作为实际执行任务的 Worker。顾问可以在开场提供计划，在工具反复失败时给出调整建议，也可由执行智能体在关键决策点主动咨询。

- 入口：智能体运行配置中的 Loop 模板，以及聊天输入栏的 Loop 模式菜单；也支持 `/advisor` 命令。
- 默认顾问使用主模型，Worker 使用子智能体模型；可以分别指定，也可以单独调整顾问的思考档位。
- 可分别控制开场计划、自动介入、主动咨询，并设置失败阈值、介入次数和主动咨询上限。
- 计划和咨询结果可流式显示；项目目录可提供 `ADVISOR.md` 作为顾问指引。
- **使用边界**：实验性功能，默认关闭；同一会话不能同时运行顾问、Goal 和其他 Loop 模式。智能体配置持久保存，会话的模式激活状态和顾问记忆不跨后端重启保留。真实模型质量、耗费及长任务表现尚未使用私人账户验证。

### 2. 决策模型工具审批

新增基于 TypeSafe/Jev 分类器的工具审批模式。确定性的权限与风险检查先执行；只有允许由决策模型评估的审批请求才进入分类器，明确禁止的动作不会被模型放行。

- 支持配置决策模型及会话审批档位，界面随模型可用状态更新。
- 决策模型不可用、请求失败或返回无法解析时，保守要求审批。
- 补充输入来源、目标、参数名称和特定已验证事实的判断，以及缓存与观测信息。
- AgentScope 主版本仍固定为 `2.0.10`，增加 `classifier-jev` 依赖项。
- **使用边界**：需要相应服务配置。测试采用隔离响应，不代表已对真实账户完成授权或业务验证。

### 3. 内联 OpenUI 交互插件

新增 `qwenpaw-openui` 插件，可在普通聊天文字之间显示由模型生成的表格、图表、表单、卡片、选项和滑块等界面。包含 OpenUI 的 82 种组件及子组件。

- 插件支持 `openui-lang` 代码块、渐进流式呈现和同一回复中的多个独立界面。
- 本地更改通过 `@Set`、`@Reset` 更新；继续或提交操作通过宿主消息队列发送可见消息。
- 外链通过宿主统一打开器处理；共享宿主 React，并适配主题。
- 本轮已构建插件发布入口和系统提示词，并执行 66 项插件前端测试。
- **使用边界**：需要安装并启用插件；不会取代 UGSci GenUI，也未新增独立 UGSci 设置侧栏入口。刷新会恢复界面初始值；未接入 Query、Mutation、任意工具提供者或历史界面补丁。

### 4. 插件安全卸载、可回滚热重载与公共 SDK

插件生命周期从若干分散操作转为统一的加载、激活、卸载和恢复流程。

- 卸载会撤销插件贡献的工具、命令、路由、服务及工作区资源；热重载失败可恢复上一代插件。
- 活跃任务和资源尚未停止时，有明确的忙碌状态及中断确认，避免界面把不完整卸载显示为成功。
- 禁用、已加载、失败和需要重启等状态有更细的显示及诊断。
- 插件依赖在启动时检测，修复或安装为显式操作；限制插件覆盖宿主依赖，保留失败关闭和恢复路径。
- 新增独立的 Python/前端插件 SDK、能力声明、上下文服务、受控工具调用、任务启动/流式观察/取消、存储、事件、渠道和应用接口，以及作者验证入口。
- **本分支适配**：保留领域 Operation/Run Executor 注册、工具权限元数据、UGSci 设置与宿主原生页面加载接口，保留组件更新及明确卸载后的防重装标记。

### 5. Firecrawl 网络搜索

`web_search` 新增 Firecrawl 提供方，可在工具配置中选择。API 密钥可选；配置密钥遭遇 HTTP 401 时会尝试一次匿名请求，限流等失败有明确提示。

这只是新增搜索后端，不改变已有 Tavily/AnySearch 配置。匿名可用性和额度由第三方服务决定，本轮未验证真实外网搜索账户。

### 6. 模型管理体验调整

调整全局模型设置、提供方分组、云端/本地切换、搜索、凭证字段和模型编辑界面；增强智能体的主模型、子智能体模型、决策模型与顾问/Worker 模型配置体验，并改进思考能力字段及模型胶囊显示。

这些界面仍使用原有模型提供方和配置持久化体系。本分支已有提供方设置在重载时保留的修复继续合入。

### 7. ACP 接入增强

ACP 增加 `--agent-mode`，可为新会话选择 Goal、Mission、自定义或插件模式，并支持 Goal token 预算参数。修复长工具调用后的任务结果丢失及退出语义，避免协议标准输出被普通日志污染。模式选择不改变 ACP 权限设置。

### 8. 子路径部署和跨智能体聊天链接

- 前端支持配置站点子路径，统一路由和静态资源前缀；API 地址独立配置。
- 聊天深链接先解析会话归属，必要时切换正确智能体；解析失败提供明确状态和重试。
- 会话切换期间隔离旧请求、审批、终端、文件面板和插件提交，减少串会话问题。
- **本分支保留**：专家召唤、直接指派/协作、工作区事件和自定义显示名继续使用宿主路由与提交上下文。

### 9. QwenPaw-Data 应用更新

应用更新到上游 `1.0.3`，相关 Data Context、Host Core、CLI、Skills 的最低依赖提高到 `0.3.3`；补充模型设置、独立运行、服务生命周期和宿主网关验证。修正应用上传 ZIP 大小及宿主版本范围信息。

服务启动环境按应用显式授权隔离，支持受管进程重启和停止。真实 Data 服务、模型供应商及私人数据集没有在本轮调用。
