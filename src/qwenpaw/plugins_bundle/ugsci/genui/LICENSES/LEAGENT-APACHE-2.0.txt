This license applies to code ported from the LeAgent project
(https://github.com/leagent/leagent) into the QwenPaw UGSci plugin's
GenUI module. The following files contain code derived from LeAgent:

- schema.py        — UI tree schema, component catalog, validation
- json_repair.py   — JSON repair pipeline for malformed LLM output
- guide.py         — GenUI guide payload for the model
- tools.py         — emit_ui_tree, list_ui_components, get_genui_guide tools

Modifications: Removed LeAgent-specific dependencies (ServiceManager,
CanvasService, ArtifactService, BaseTool, ToolContext). Adapted to
QwenPaw's plugin tool registration system and ToolChunk result format.
